3. KEY INDICES
----------------------------------------------------------------------

Relative Alpha (RA): log(Right Alpha) - log(Left Alpha)
  - Positive RA: greater left frontal activity (approach motivation)
  - Negative RA: greater right frontal activity (withdrawal)

RSMR: SMR Power / Alpha Power
  - Higher values indicate focused attention

Engagement Index: Beta / (Alpha + Theta)
  - Higher values indicate greater cognitive engagement
